# MVP

## 첫 Vertical Slice

### Grid

- 약 8×10
- Height 0~2

### 전투 구성

- Player: 3 Units
- Enemy: 약 4 Units부터 시작
- Player archetype: Warrior, Mage, Archer
- 각 캐릭터: 기본 행동과 Skill 약 2개
- 초기 Status: Burn, Stun, Shield

### 필수 전투 요소

- Move
- AP
- Skill
- Range
- LOS
- Height
- Enemy Intent
- Win / Lose

## 첫 로그라이크 검증

Battle 1 → Upgrade 3개 제시 → 1개 선택 → Battle 2

성공 기준은 **첫 번째 전투에서 선택한 Upgrade 때문에 두 번째 전투의 플레이 방식이 실제로 달라지는가?**이다.
